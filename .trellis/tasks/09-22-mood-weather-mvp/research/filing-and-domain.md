# 小程序自建后端的备案与域名核验（2026-09-22）

## 用户提供的现状

- 已有后端服务器，用户称已有 ICP 备案，计划仅提供本产品的 API 接口，不部署本产品的网页前端。
- 尚未办理公安联网备案；先前表述为“未通过”是误解，实际并未提交申请。
- 用户在 Cloudflare 部署的前端属于另一个项目，与本产品无关。

## 官方及服务商材料

- 微信小程序备案操作指引：新上架小程序需办理自身备案，管局审核完成并取得小程序备案号后才能进入版本发布流程。这独立于既有网站/域名 ICP 备案。来源：https://developers.weixin.qq.com/miniprogram/product/record_guidelines.html
- 微信服务器域名配置说明：网络请求限已配置的服务器域名，使用 HTTPS；域名不能是公网 IP 或 localhost，必须经过 ICP 备案，证书有效且可信。来源：https://developers.weixin.qq.com/minigame/dev/guide/base-ability/network （同系微信网络能力文档，具体小程序配置以公众平台为准）
- 深圳市公安局网站备案指引：网站在工信部备案成功、开通后应在 30 日内提交公安联网备案；未通过受理时需按要求更正或完善材料。来源：https://ga.sz.gov.cn/ZT/HLWSYSQ
- 腾讯云公安联网备案指引（服务商参考，非主管部门最终认定）：未实际搭建上线且无法公网访问的网站，或仅提供 API 接口、无面向用户网页内容的网站，列为可暂不办理的情形。来源：https://cloud.tencent.com/document/product/243/19142

## 对本任务的结论和待核验项

- 可以以自建服务器为首版架构候选并继续在本地/测试环境规划开发；不把“公安备案未通过”误判为小程序编译或 API 编码阻碍。
- 不能据此承诺已经具备公开发布资格。发布前应核对微信小程序备案、合法 request 域名、证书和具体公安备案义务；若公安申请被驳回，需看通知中的具体原因并向当地主管部门/服务商核实。
- 用户计划的是纯 API 服务。腾讯云文档提示这种情形可能暂不办理网站公安联网备案，但该服务商说明不能替代所在地主管部门的认定；若以后增加面向用户的网站，应重新核验义务。
- 不应要求用户在聊天中发送服务器密码、AppSecret、数据库口令或包含个人身份信息的备案材料。
