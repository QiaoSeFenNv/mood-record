# 小程序界面重设计

## Goal

重做心情晴雨表小程序的页面视觉、信息层级与文案，让个人能够迅速记录当下心情、看见当天痕迹，并在匿名共鸣与回顾中获得陪伴感和对变化的理解。

## Background

- 用户确认设计目标覆盖小程序，而非 API 或共享包；页面信息层级与文案可以一起优化。
- 保留现有产品核心能力和真实数据链路：今天的心情树与快速记录、24 小时时间线、匿名共鸣、七天回顾与个人数据控制。
- 现有小程序基于 uni-app / Vue 3，主导航为“今天 / 回顾 / 我的”，并有本地测试身份入口。
- 原 MVP PRD 要求情绪表达非评判、个人记录默认私密、共鸣人数明确标注为匿名趋势估算；正式微信登录不在当前阶段冒充已完成。
- 当前界面以深色渐变、发光图形和大量圆角卡片为主；用户认为现状不理想。浏览器 H5 预览可运行，但不能替代微信小程序验收。
- 用户确认保留心情树的反馈机制与不同情绪痕迹共存，但旧版“梦幻发光分层插画”不是必须保留的视觉约束；原 MVP 的插画和逐帧动效条款须随最终方向同步调整。
- 用户否定 Impeccable 第一轮备选方案；用户提供的参考图呈现明亮蓝紫天空、草地、柔和童话感与陪伴角色。参考图是宣传拼图，不作为实际页面布局模板。
- 用户希望将参考图中的人物改为原创动物伙伴，并让用户选择植物；首版确定为 2 种动物伙伴与 2 种植物，后续按反馈迭代。
- 首次进入使用默认动物与植物组合，不强制选择；用户可在“我的”随时更换。选择首版仅保存在本机，不要求跨设备同步。
- 用户自行按本任务的提示词生成原创位图，放入约定的项目位置；视频可以考虑，但不作为首版可用性的依赖。

## Requirements

- 重新组织三处主页面的视觉层级，让“今天”的心情树与快速记录成为首屏主任务，回顾可供扫描，数据控制清晰可辨。
- 快速记录改为“拖动时预览心情树与当前情绪，松手后等待用户显式确认，确认后才写入一条记录”；用户可在确认前继续调整或放弃。保存中不可重复提交，失败后保留选择并允许重试，成功后继续提供 5 秒撤销。
- 改善视觉表达和中文文案，保留接纳、克制的语气，不增加医疗判断或虚构共鸣数据。
- 心情树仍须在首屏清楚呈现，记录预览、提交、撤销与删除后能对应变化；新画风不得以枯萎或扣分表达低落。
- 动物伙伴和植物选择只影响视觉表现，不改变情绪含义、记录数据或共鸣口径；角色与植物均须与用户提供的参考区分，避免直接复制其现有形象。
- 首版提供两种原创动物伙伴和两种植物外观，其中一种是树，另一种是花或灌木；两种植物均能承载五段心情的共存痕迹。
- 外观选择在本机重新打开后仍保留；清楚告知用户换设备不会同步。形象切换不改变既有心情记录、时间轴和匿名统计。
- 新视觉参考用户提供的明亮蓝紫天空、柔和草地与陪伴关系：首屏是一处可交互的植物场景，记录控件和状态必须清楚，不照搬参考图的宣传拼图、手机边框或角色。
- 首版使用静态分层场景并支持低动效。视频仅作为以后经微信真机性能验证后的可选氛围层；缺少视频时界面完整可用。
- 保留已有记录、撤销、删除、导出、设置和导航能力；设计改造不得破坏 API 契约、隐私说明或小程序运行。
- 空状态、保存中、网络失败、撤销和危险操作保持清楚且可恢复。
- 兼顾 H5 预览与微信小程序的尺寸、性能和低动效设置。

## Acceptance Criteria

- [ ] “今天 / 回顾 / 我的”三处页面在窄屏上无裁切、错位或层级混乱，导航与主要操作可辨。
- [ ] 新用户能从首屏找到记录入口；已登录用户能够按确认后的提交规则完成记录并看到树、共鸣和时间线变化。
- [ ] 仅拖动或松开滑杆不会写入记录；点击确认后最多创建一条记录，失败可沿用同一幂等标识重试。
- [ ] 空数据、加载、保存失败、撤销及删除确认状态有一致且明确的反馈。
- [ ] 匿名趋势估算、测试环境、私密记录和危险操作文案准确，不新增不实承诺。
- [ ] 首次进入不被形象选择阻断；用户可在“我的”从两种动物和两种植物中分别选择，重开小程序后本机选择仍在，切换形象不改动记录数据。
- [ ] 两种植物都能显示五段情绪留下的共存痕迹；切换植物后仍可从记录重新生成，低动效模式下信息不缺失。
- [ ] 用户按 `asset-prompts.md` 提供的场景与角色素材被正确加载，缺图不会被误判为完成；视频缺席不影响任何操作。
- [ ] 两种动物伙伴和两种植物在手机屏幕上清楚可辨，不复制参考图已有的形象；场景图片与操作层不互相遮挡。
- [ ] 现有相关测试、类型检查、小程序构建和 H5 构建通过；H5 页面经过桌面与手机尺寸视觉核验。

## Out of Scope

- 后端算法、认证机制、数据模型和正式发布配置。
- 心理诊断、社交功能、排行榜或新增记录字段。
- 首版自动播放视频、跨设备同步外观设置、更多动物和植物。

## Asset Dependency

- 用户将按 [asset-prompts.md](./asset-prompts.md) 生成并放置 5 张原创图片；相关页面功能可以先实现，但最终视觉验收必须等素材到位。
- 最终方向以用户参考图及本任务要求为准，详见 [design.md](./design.md) 与页面方向契约。
