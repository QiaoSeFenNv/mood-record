# 插画交付清单与生图提示词

用户自行生成并放置成品；本文件只定义首版素材，不要求上传密钥。参考图为用户提供的移动产品宣传拼图，仅借鉴明亮蓝紫天空、轻盈草地和陪伴感，不复制其中的羊、人物、手机界面或版式。

## 文件位置与规格

将最终素材放在 `apps/miniapp/src/static/scene/`，文件名固定如下。生成器若不能直接输出指定尺寸，可保持比例后导出；透明图必须保留真实 alpha，不要用白底或棋盘格伪装透明。

| 文件名 | 建议尺寸 | 用途 |
| --- | --- | --- |
| `meadow-sky.png` | 1080 x 1920，9:16 | 无角色、无植物的场景底图 |
| `leaf-tree.png` | 1200 x 1600，3:4，透明 | 默认的年轻小叶树 |
| `camellia-shrub.png` | 1200 x 1600，3:4，透明 | 可选的山茶花灌木 |
| `fawn.png` | 800 x 800，透明 | 默认动物伙伴小鹿 |
| `tit-bird.png` | 800 x 800，透明 | 可选动物伙伴山雀 |

所有素材采用同一个视觉母版：柔和但清晰的半立体绘本插画，少量手绘纹理，圆润但不过度幼态；天空是通透的蓝、淡紫和粉云，草地是清新的青绿，局部有暖金与珊瑚色点缀。哑光材质、自然的左上方柔光、干净轮廓、可在手机小尺寸下辨认。不要黑夜、深海、霓虹、发光圆球、浓雾、过度景深、摄影真实感或高亮塑料玩具质感。五段心情的雨滴、露珠、柔光、金叶和花朵由界面上的独立痕迹层绘制，基础植物不要自带某一种情绪的天气。

每次生成时把用户提供的图片作为**气氛参考**上传，不作为编辑目标；不要要求模型复制原图中的形象或手机 UI。对五个素材尽量使用同一模型、同一风格参考与同一光照描述。

## 1. 场景底图 `meadow-sky.png`

```text
用途：微信小程序“今天”页面的原创竖版场景背景，9:16，高清位图。
画面：清透的蓝紫色天空过渡到浅粉云层，下方约 18% 是柔软、层次细腻的青绿色草坡；少量小花和草叶只放在左右边缘。画面中央约 65% 保持干净，供前景植物和动物叠放；上方留出日期标题的可读空间。明亮、温柔、有呼吸感，像高品质半立体绘本插画，不是宣传海报。
光照：左上方柔和自然光，哑光材质，轻微手绘纹理，色彩丰富但不过饱和。
参考图只用于蓝紫天空、草地和陪伴感的气氛，不复制布局或已有角色。
不要：树、灌木、动物、人物、手机、卡片、按钮、文字、logo、水印、星球、发光圆球、黑夜、深海、强烈渐变条纹。
```

## 2. 默认植物 `leaf-tree.png`

```text
用途：移动端心情记录场景的独立前景植物插画，3:4 竖版，真实透明背景 PNG，完整轮廓四周留 8% 安全边距。
主体：一棵年轻、舒展的小叶树，清楚的树干、开放的枝条、轻盈的青绿色叶冠；树冠有足够空隙供界面稍后叠加雨滴、露珠、柔光、金叶和花朵，地面根部可见。树健康而中性，不表现某种心情好坏。
风格：与场景底图一致的高品质柔和半立体绘本插画，哑光细腻纹理，左上方柔光，清晰而不硬的边缘，适合缩到手机屏幕宽度的一半仍可辨认。
构图：正面略带三分之二视角，植物居中，完整树冠和根部都在画面内；只保留自然的轻微接地阴影，背景完全透明。
不要：盆栽、果实、枯叶、萎缩、动物、人物、文字、边框、背景场景、白底、棋盘格底、水印、夸张霓虹光效。
```

## 3. 可选植物 `camellia-shrub.png`

```text
用途：与“年轻小叶树”同一小程序中的第二种可选心情植物，3:4 竖版，真实透明背景 PNG，完整轮廓四周留 8% 安全边距。
主体：一丛舒展的山茶花灌木，有清楚的分枝、青绿叶片和少量未开的花苞；整体轮廓与树明显不同，体量仍足以承载后来叠加的雨滴、露珠、柔光、金叶和花朵。基础状态健康、中性，不预设用户情绪。
风格、光照和视角与同系列的年轻小叶树完全一致：高品质柔和半立体绘本、哑光细腻纹理、左上方柔光、适合手机小尺寸。
构图：主体居中，完整枝叶与根部可见，四周留空；只有轻微接地阴影，背景完全透明。
不要：盛开的大面积花朵、花盆、枯萎、动物、人物、文字、边框、背景场景、白底、棋盘格底、水印、霓虹光效。
```

## 4. 默认伙伴 `fawn.png`

```text
用途：微信小程序场景中的原创动物伙伴独立插画，正方形，真实透明背景 PNG，完整轮廓留 8% 安全边距。
主体：一只安静、友善的小鹿，坐在草坡上的自然姿态，眼神温和而不拟人化，不穿衣服、不持道具。形象有独立辨识度，不能像参考图中的羊或任何现成 IP。它只是陪伴者，不因为用户心情变化而奖励、难过或责备。
风格：与蓝紫天空和植物素材一致的柔和半立体绘本插画，哑光绒感与少量手绘纹理，左上方柔光，圆润但不过度婴儿化；缩小到手机约 70-90 像素宽时仍有清晰剪影。
构图：轻微三分之二视角，身体完整，四周留空，轻微接地阴影；背景完全透明。
不要：人形身体、夸张表情、眼泪、翅膀、服装、文字、背景、白底、棋盘格底、水印、参考图原有羊形象。
```

## 5. 可选伙伴 `tit-bird.png`

```text
用途：与小鹿同系列的第二种原创动物伙伴独立插画，正方形，真实透明背景 PNG，完整轮廓留 8% 安全边距。
主体：一只小山雀，圆润但保留鸟的真实结构，可自然停在低枝或草茎旁，眼神温和、姿态轻盈；不拟人化、不穿衣服、不持道具。形象不能借用任何现成 IP，也不随心情变成奖惩角色。
风格、光照、材质与小鹿、树和灌木保持统一：柔和半立体绘本、哑光细腻纹理、左上方柔光；缩小到手机约 70-90 像素宽仍有清楚剪影。
构图：完整身体与尾羽在画面内，四周留空，不带整根树枝或场景；背景完全透明。
不要：人形身体、夸张表情、眼泪、服装、文字、背景、白底、棋盘格底、水印、参考图原有角色。
```

## 可选视频，不阻塞首版

视频仅作为将来的无声氛围层，不包含植物、动物、心情痕迹或操作 UI；首版静态场景必须独立成立。若制作，请放在 `apps/miniapp/src/static/scene/meadow-loop.mp4`，竖版 9:16，6-8 秒、可无缝循环、静止镜头、轻微云层和草叶运动、无闪光和声效。低动效模式必须停在静态背景。视频包体、自动播放和微信真机性能通过验证前不接入默认体验。

```text
用途：与 meadow-sky.png 同构图的可选无声背景循环视频，9:16，6-8 秒。
固定镜头，只有远处蓝紫天空中的淡粉云缓慢移动、画面底部草叶轻轻摆动；中央留空，首尾帧可无缝衔接。明亮柔和的半立体绘本质感，光照和色彩与静态图一致。
不要：镜头推拉、植物主体、动物、人物、文字、UI、闪烁、粒子爆发、音频、昼夜切换、快速运动。
```
