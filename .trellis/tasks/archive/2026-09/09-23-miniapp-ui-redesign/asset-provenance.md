# 场景素材来源与处理

五张图片均通过项目的 `l0veyou-imagegen` skill 使用 `gpt-image-2-5-full` 生成，生成提示词见 [asset-prompts.md](./asset-prompts.md)。具体提示词已嵌入各 PNG 的 `prompt` 元数据；素材位于 `apps/miniapp/src/static/scene/`。图片仅作为本小程序的原创插画使用，未引用参考图中的现成角色或界面。

| 文件 | 输出与处理 |
| --- | --- |
| `meadow-sky.png` | 按 9:16 提示词生成的不透明场景图，但接口返回方形图。裁去过多的上方天空并重新取景，使草地在小程序首屏可见；交付尺寸为 600 × 600。页面使用 `aspectFill`，已检查手机与桌面预览中的草地和植物落点。 |
| `leaf-tree.png` | 初次输出包含绘制的棋盘格，弃用；再次要求纯白背景，按与白色的色差生成真实 alpha，缩小到 440 × 587。 |
| `camellia-shrub.png` | 初次输出包含绘制的棋盘格，弃用；再次要求纯白背景，按与白色的色差生成真实 alpha，缩小到 440 × 587。 |
| `fawn.png` | 输出包含绘制的棋盘格；用本地 `rembg` 去背，人工检查轮廓后缩小到 360 × 360。 |
| `tit-bird.png` | 输出包含绘制的棋盘格；用本地 `rembg` 去背，人工检查轮廓后缩小到 360 × 360。 |

最终四张前景图均有真实透明像素，场景图不要求透明。图片处理未保存授权令牌。视频未生成或接入，静态场景本身完成首版体验。
