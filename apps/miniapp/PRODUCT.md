# Product

## Platform

web

基于 uni-app / Vue 3 的微信小程序，同时提供 H5 浏览器预览；H5 不替代微信开发者工具与真机验收。

## Users

想在日常片刻低负担地记录情绪的个人用户。一次记录不要求长文字，之后可以回看一天及一周的变化。

## Product Purpose

用户通过连续心情控件快速记录当下情绪，在心情树与时间线上看见当天留下的痕迹，并通过匿名共鸣获得“此刻有人和我一样”的陪伴感。回顾帮助用户理解自己的变化，不提供心理诊断或治疗结论。

## Positioning

将快速的连续心情记录、同一天可共存的心情树痕迹，以及披露估算口径的匿名即时共鸣结合在一个私密体验中。

## Operating Context

主导航为“今天 / 回顾 / 我的”。目前仅有本地测试身份，连接真实 API 和持久化数据库；正式微信登录和公开发布尚未完成。用户可以多次记录、撤销刚提交的记录、查看时间线与七天回顾，并控制自己的数据。

## Capabilities and Constraints

- 个人记录默认私密；共鸣来自同段心情的匿名去重用户数，展示人数为趋势估算，不能宣称精确实时人数。
- 支持 CSV 导出、单条删除、全部清除和账号注销；危险操作需要明确确认。
- 情绪表达接纳且非评判，不把低落表现为惩罚，不增加诊断或疗效承诺。
- 记录交互将改为拖动预览、松手后显式确认保存；确认前不得写入记录。
- 低动效与触觉反馈设置须保留，设备不支持触觉反馈时仍可记录。
- 首版提供两种原创动物伙伴与两种植物外观（一棵树、一种花或灌木）；首次进入有默认组合，用户在“我的”更换，偏好仅保存在本机且不跨设备同步。两种植物均表现五段心情痕迹，外观不改变记录、回顾或共鸣数据。

## Brand Commitments

产品名为“心情晴雨表”，心情树是核心识别与反馈机制。树的具体画风可以重做，不必延续旧版梦幻发光插画。中文表达保持温和、克制、非评判。

## Evidence on Hand

现有页面、组件和真实 API 位于 `apps/miniapp/src/`；完整 MVP 产品规则位于 `.trellis/tasks/09-22-mood-weather-mvp/prd.md`。当前共鸣和测试环境说明必须保留真实性，不得编造真实用户或统计。

## Product Principles

- 让一次记录足够快，不迫使用户解释情绪。
- 允许不同心情在同一天并存，不评定好坏。
- 用真实、可解释的数据表达共鸣，同时守住个人隐私。
- 让回顾支持观察，而不是下诊断或驱动打卡压力。
